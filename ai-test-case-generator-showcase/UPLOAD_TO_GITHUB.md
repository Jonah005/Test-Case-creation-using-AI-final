# Uploading This Showcase to GitHub

## Recommended repository name

`ai-test-case-generator`

## Recommended GitHub description

`Research showcase for cross-language AI test generation using StarCoderBase-1B, LoRA, and control-flow analysis.`

## Suggested topics

`python` `llm` `software-testing` `test-generation` `starcoder` `lora` `control-flow-graph` `research` `ieee` `rust` `javascript`

## Upload from the command line

```bash
git init
git branch -M main
git add .
git commit -m "Create public research showcase"
git remote add origin https://github.com/Jonah005/ai-test-case-generator.git
git push -u origin main
```

Create the empty GitHub repository first and do not initialize it with another README if you are using the commands above.
