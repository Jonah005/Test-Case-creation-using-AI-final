## Research Focus

The work presents a cross-language automated test-generation framework combining:

- transformer-based code generation
- StarCoderBase-1B
- LoRA fine-tuning
- Control Flow Graphs
- source-code parsing
- automated unit-test generation
- evaluation across Python, JavaScript, and Rust
